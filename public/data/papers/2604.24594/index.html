Skill Retrieval Augmentation for Agentic AI

Authors: Weihang Su, Jianming Long, Qingyao Ai, Yichen Tang, Changyue Wang, Yiteng Tu, Yiqun Liu

Source: https://arxiv.org/abs/arXiv:2604.24594

Generated summary artifact for 2604.24594

Thesis

The paper proposes Skill Retrieval Augmentation (SRA) as a new paradigm for augmenting agentic LLMs with external capabilities at scale, moving beyond fixed in-context skill injection. It argues that effective SRA requires addressing not only skill retrieval but also robust skill incorporation and application, establishing a research agenda for scalable capability augmentation.

Core Problem

Existing agent systems using Large Language Models (LLMs) struggle to scale external skill usage because explicitly enumerating available skills in the context window consumes context budgets rapidly and degrades reasoning and selection accuracy as skill corpora grow.

Key Novelty

Formulation of Skill Retrieval Augmentation (SRA) as a new paradigm for scalable capability augmentation in agentic AI and introduction of SRA-Bench, the first benchmark for decomposed evaluation of the SRA pipeline.

Key Contributions

  • SRA-Bench, a new large-scale benchmark for Skill Retrieval Augmentation, includes 5,400 test instances and 26,262 skills, supporting decomposed evaluation across skill retrieval, incorporation, and application.
  • Experiments show that external skills significantly improve agent performance over skill-free baselines, with Oracle Skill (perfect skill access) consistently outperforming LLM Direct by large margins (e.g., +16.6% average for Llama-3.3-70B).
  • LLM Selection consistently outperforms other practical SRA methods (Full-Skill Injection, Progressive Disclosure) in end-task performance, demonstrating its effectiveness and stability in utilizing retrieved skills.
  • LLM-based reranking significantly boosts skill retrieval quality (e.g., +61.9% R@1 on MedCalc-Bench for Qwen3-32B over BM25) and subsequently improves end-task performance.
  • Findings highlight a critical bottleneck in skill incorporation: current LLMs are often not relevance-aware (loading skills even without gold skills) or need-aware (loading skills indiscriminately regardless of native competence), severely limiting scalable skill augmentation.

Results

  • External skills can substantially improve agent performance when correctly accessed and used, validating the SRA paradigm's promise.
  • Practical retrieval-based SRA methods can yield meaningful gains, but these are uneven and remain substantially below the Oracle Skill upper bound, indicating a need for robust practical inference settings.
  • The effectiveness of SRA critically depends on how retrieved skills are exposed and utilized, with LLM Selection generally outperforming Full-Skill Injection and Progressive Disclosure in terms of effectiveness and stability.
  • LLM-based reranking provides the strongest overall retrieval performance, indicating that skill retrieval involves more than just topical similarity, but also recognizing actionable capabilities.
  • Retrieval quality is a necessary but insufficient condition for strong SRA performance; improvements are mediated by downstream skill incorporation and execution.
  • Current LLMs lack reliable relevance-awareness and need-awareness in skill loading, often loading skills indiscriminately or regardless of native capability gaps, leading to skill-loading hallucination.
  • Frontier models (GLM-5.1, GPT-5.4) show stronger relevance-awareness than open-source models, but still fall short of ideal behavior, suggesting a fundamental bottleneck in controlled skill utilization.

Limitations

  • Current LLM agents tend to load skills at similar rates regardless of whether a gold skill is retrieved or the task requires external capabilities, indicating a fundamental absence of need-aware skill invocation.
  • Scalable skill augmentation is bottlenecked not only by retrieval quality but also by the base model's ability to determine which skill to load and when external loading is actually needed.
  • SR-Agents are highly brittle to retrieval noise; performance degrades sharply as distractors accumulate, especially under Full Skill Injection, suggesting poor robustness.
  • Most current LLMs are not reliably relevance-aware when incorporating skills, often loading skills at substantial rates even when no gold skill is present (skill-loading hallucination).
  • Current LLMs generally lack need-awareness, showing similar skill-loading rates for tasks they can solve natively and tasks that exceed their native capabilities.
