COLLEAGUE.SKILL: Automated AI Skill Generation via Expert Knowledge Distillation

Authors: Tianyi Zhou, Dongrui Liu, Leitao Yuan, Jing Shao, Xia Hu

Source: https://arxiv.org/abs/arXiv:2605.31264

Generated summary artifact for 2605.31264

Thesis

COLLEAGUE.SKILL proposes an automated trace-to-skill distillation system that transforms heterogeneous human traces into portable, inspectable, correctable, and agent-usable AI skill packages, framed as an artifact problem to enable governance, auditability, and controlled deployment rather than opaque identity simulation.

Core Problem

Building person-grounded AI agents with human expertise, judgment, and interaction style is difficult because this knowledge is often dispersed across heterogeneous data traces (e.g., code comments, chat decisions, interviews) instead of being clean instructions. There is no end-to-end workflow to distill these traces into inspectable, correctable, and agent-usable skills.

Key Novelty

COLLEAGUE.SKILL formulates person-grounded trace-to-skill distillation as an artifact problem, producing inspectable, correctable, and portable AI skill packages with a dual representation of capability and behavior, and supporting a full lifecycle for governance and deployment.

Key Contributions

  • The system successfully distills heterogeneous human traces into structured, versioned, and inspectable skill packages with a dual capability and behavior representation.
  • Correction and rollback mechanisms are implemented, allowing skills to be improved over time through natural-language feedback while preserving prior states.
  • COLLEAGUE.SKILL's open-source deployment includes a public gallery listing over 200 skills from 165 contributors and more than 100k cumulative stars, demonstrating a strong community ecosystem and public distribution surface.
  • The framework is adaptable to diverse, sensitive domains (colleague, celebrity/public-figure, relationship) through application presets that manage source requirements, consent, and governance.
  • The artifact-level claims focus on inspectability, portability, and governance rather than behavioral fidelity, enabling clearer evaluation protocols for future work.

Results

  • COLLEAGUE.SKILL provides an automated workflow to distill human traces into inspectable, correctable, and portable AI skill packages, addressing a critical gap in current LLM agent capabilities.
  • The dual representation (capability and behavior tracks) in the generated artifacts allows for clear separation and independent invocation of functional knowledge and interaction style, enhancing transparency and control.
  • The system is designed for a full lifecycle, including creation, correction, versioning, and deployment across multiple agent hosts and sharing surfaces, supported by an open-source community ecosystem.
  • Application presets for 'colleague', 'celebrity/public-figure', and 'relationship' domains demonstrate the framework's versatility and its ability to handle different source, consent, and governance requirements.

Limitations

  • The paper focuses on the artifact format, workflow, implementation, and public deployment surface, leaving open questions regarding source quality, extraction quality, model behavior, emotional safety, and user trust calibration.
  • Real deployments will necessitate explicit participation, scoped source collection, access controls, retention limits, and non-mandatory use, as well as separate review for lawful source use, consent, and full redaction.
  • Corrections, while improving artifacts, could introduce editor bias or make contested traces appear more settled than they are.
