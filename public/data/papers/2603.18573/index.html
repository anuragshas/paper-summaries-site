Interplay: Training Independent Simulators for Reference-Free Conversational Recommendation

Authors: Jerome Ramos, Feng Xia, Xi Wang, Shubham Chatterjee, Xiao Fu, Hossein A. Rahmani, and Aldo Lipani

Source: https://arxiv.org/abs/arXiv:2603.18573

Generated summary artifact for 2603.18573

Thesis

The paper proposes Interplay, a reference-free simulation framework that trains independent user and recommender LLM simulators without predetermined outcomes to generate realistic, diverse, and flexible conversational recommendation dialogues, addressing the oracle problem and data leakage issues of prior methods.

Core Problem

Training conversational recommender systems (CRS) requires extensive dialogue data, which is challenging to collect at scale. Traditional simulation approaches using single LLMs or reference-dependent generation lead to scripted, artificial, rigid dialogues with data leakage and limited realism.

Key Novelty

A reference-free simulation framework that trains independent user and recommender LLM simulators without predetermined outcomes for conversational recommender systems, eliminating the oracle problem and data leakage.

Key Contributions

  • Achieved 93-95% success rates for user simulators without target leakage, substantially outperforming larger zero-shot LLMs (Llama3.1 70B and Qwen3 32B).
  • User simulators maintained superior BERTScore for single-turn response quality, indicating contextually appropriate utterances without target knowledge.
  • Recommender simulators (RecSim-Qwen8B) outperformed larger baselines like Qwen3-32B and modular systems like UniCRS in Recall@1 and Match Score.
  • Human evaluations confirmed that the reference-free dialogues generated by Interplay achieve quality comparable to reference-dependent PEARL conversations, with significantly more user control.
  • The approach utilizes smaller 8B models to achieve competitive or superior performance compared to larger 32B and 70B baselines, leading to lower computational costs.

Results

  • The proposed reference-free user simulators achieve high success rates (93-95%) and effectively address the oracle problem, significantly outperforming larger zero-shot LLMs.
  • User simulators demonstrate superior single-turn response quality with high BERTScore, indicating contextually appropriate utterances without requiring predetermined outcomes.
  • Specialized training enables recommender simulators to provide high-quality recommendations without oracle knowledge, outperforming larger general-purpose LLMs and modular CRS systems in Recall@1 and Match Score.
  • The approach generates more diverse responses and maintains appropriate lengths for both user and recommender turns compared to baselines.
  • Human evaluations confirm that the independent simulators produce realistic dialogue comparable in quality to reference-dependent methods, with improved user control and at a lower computational cost using smaller models.

Limitations

  • Domain Specificity: The empirical evaluation is confined to the movie recommendation domain; the framework's effectiveness in other domains (e.g., e-commerce, music, travel) has not yet been validated.
  • Constrained Conversational Scope: The current simulation operates within a structured, task-oriented dialogue framework that maps turns to explicit actions, which is beneficial for control but does not capture the full spectrum of real-world interactions like open-domain chit-chat or multi-intent utterances.
  • Recommendation Evaluation: MatchScore, while a useful proxy, has not been fully validated as a reliable metric aligned with real user preferences; further user studies are needed to confirm its correlation with human judgments.
