SkillOpt: Executive Strategy for Self-Evolving Agent Skills

Authors: Yifan Yang, Ziyang Gong, Weiquan Huang, Qihao Yang, Ziwei Zhou, Zisu Huang, Yan Li, Xuemei Gao, Qi Dai, Bei Liu, Kai Qiu, Yuqing Yang, Dongdong Chen, Xue Yang, Chong Luo

Source: https://arxiv.org/abs/arXiv:2605.23904

Generated summary artifact for 2605.23904

Thesis

Agent skills should be trained as the external state of a frozen agent, with the same discipline that makes weight-space optimization reproducible, rather than through ad-hoc, brittle self-revision, to reliably improve performance under feedback.

Core Problem

How can agent skills, which are natural-language procedural knowledge, be systematically optimized in a stable and reproducible manner, similar to weight-space optimization, to enable robust domain adaptation for frozen Large Language Model (LLM) agents?

Key Novelty

A systematic, controllable text-space optimizer for LLM agent skills that trains natural-language skill documents as external states, using deep-learning-like controls for stable, reproducible, and transferable improvements without modifying model weights.

Key Contributions

  • SkillOpt achieves best or tied-best performance on all 52 evaluated (model, benchmark, harness) cells across a diverse set of experiments.
  • It significantly boosts GPT-5.5's average no-skill accuracy by +23.5 points in direct chat, +24.8 in the Codex harness, and +19.1 in the Claude Code harness.
  • SkillOpt outperforms the strongest per-cell competitor (including human, one-shot LLM, and various prompt optimization/skill evolution methods) by an average of +5.4 points.
  • Optimized skills are compact (300-2000 tokens) and interpretable, typically arising from only 1 to 4 accepted edits.
  • The learned skills demonstrate strong transferability across different model scales, execution harnesses, and nearby benchmarks without further optimization or model weight changes.

Results

  • SkillOpt consistently outperforms or ties with all baselines (no-skill, human-skill, one-shot LLM, prompt-optimization, and skill-evolution methods) across all 52 evaluated model-benchmark-harness combinations.
  • The method demonstrates significant performance gains over the no-skill baseline and the strongest per-cell competitors across various frontier and smaller LLM agents.
  • Optimized skills are compact (300-2000 tokens), interpretable (assembled from 1-4 accepted edits), and encode procedural, generalizable knowledge rather than instance-specific formatting.
  • The learned skill artifacts show strong transferability across different model scales, execution harnesses, and related benchmarks, highlighting their reusability without modifying model weights.
  • Key design choices like bounded textual learning, validation gating, rejected-edit feedback, and epoch-wise slow/meta updates are crucial for the observed gains, indicating a robust, controlled training loop.

Limitations

  • The optimization loop relies on scored trajectories and reliable feedback signals (e.g., automatic verifiers, exact-match metrics), making it less suitable for open-ended domains where success is subjective, multi-dimensional, or costly to judge.
  • Training skills requires additional rollout computation and optimizer model calls, incurring a cost that is amortized over reuse but may be less attractive for one-off tasks.
  • SkillOpt intentionally optimizes a single portable skill for a target domain, which might be insufficient for highly heterogeneous domains requiring many disjoint procedures or a large skill library.
  • Optimized skills can encode domain-specific heuristics from the training distribution, necessitating careful held-out evaluation before transferring them to substantially different models, harnesses, or task settings.
