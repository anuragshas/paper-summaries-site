MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens

Authors: Yu Chen, Runkai Chen, Sheng Yi, Xinda Zhao, Xiaohong Li, Jianjin Zhang, Jun Sun, Chuanrui Hu, Yunyun Han, Lidong Bing, Yafeng Deng, Tianqiao Chen

Source: https://arxiv.org/abs/arXiv:2603.23516

Generated summary artifact for 2603.23516

Thesis

Memory Sparse Attention (MSA) provides a scalable foundation for general-purpose LLMs to acquire intrinsic, lifetime-scale memory by offering an end-to-end trainable framework with linear complexity that efficiently processes up to 100M tokens with minimal performance degradation, thereby decoupling memory capacity from reasoning capabilities.

Core Problem

Large Language Models (LLMs) are fundamentally constrained by their full-attention architectures, limiting their effective context length and hindering their ability to process lifetime-scale information efficiently and without significant performance degradation.

Key Novelty

MSA (Memory Sparse Attention): An end-to-end trainable, scalable sparse attention framework that integrates sparse attention with document-wise RoPE, KV-cache compression, and Memory Interleave to achieve lifetime-scale memory in LLMs with linear complexity and minimal degradation.

Key Contributions

  • MSA achieves state-of-the-art performance on a comprehensive suite of nine question answering benchmarks, demonstrating consistent superiority over retrieval-augmented generation (RAG) baselines built on the same Qwen3-4B-Instruct backbone, with average improvements of 16.0%, 11.5%, and 14.8% over standard RAG, RAG with reranking, and HippoRAG2, respectively.
  • When compared against best-of-breed RAG systems, MSA achieves top performance on four out of nine datasets and maintains a competitive average score.
  • MSA demonstrates exceptional stability on the 'Needle-In-A-Haystack' (NIAH) benchmark, retaining 94.84% accuracy at 1M tokens with only a 3.93-percentage-point degradation from 32K tokens, while baseline LLMs and external memory systems suffer catastrophic degradation at this scale.
  • Ablation studies confirm the critical impact of curriculum learning (7.6% average gain), memory interleave (5.3% average gain), continual pre-training (31.3% average gain), and original document text integration (37.1% average gain) on MSA's performance.

Results

  • MSA consistently outperforms both same-backbone and best-of-breed RAG systems on long-context QA tasks by a significant margin.
  • MSA exhibits exceptional robustness and stability in extreme long-context settings (100M tokens), with minimal performance degradation, unlike other LLMs and memory agents that suffer catastrophic drops.
  • The proposed components—curriculum learning, memory interleave, continual pre-training, and original text integration—are all crucial for MSA's high performance and scalability, as demonstrated by ablation studies.
  • MSA achieves near-linear computational complexity during both training and inference, making it efficient for massive memory scaling.
  • The tiered memory storage strategy, with GPU-resident routing keys and CPU-offloaded content KVs, enables 100M-token inference on practical hardware setups (e.g., 2 NVIDIA A800 GPUs).

Limitations

  • While MSA enhances intrinsic latent-state memory for long textual contexts, it remains limited when tasks require modeling strong and tightly coupled dependencies across multiple documents.
  • In scenarios where evidence is distributed and highly interlinked across sources, the method struggles to maintain accurate structural alignment purely through intrinsic memory.
  • The effectiveness of Memory Interleave depends on more efficient and principled designs that better preserve inter-document relationships, suggesting room for improvement in complex relational reasoning.
