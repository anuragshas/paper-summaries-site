Meta-Harness: End-to-End Optimization of Model Harnesses

Authors: Yoonho Lee, Roshen Nair, Qizheng Zhang, Kangwook Lee, Omar Khattab, Chelsea Finn

Source: https://arxiv.org/abs/arXiv:2603.28052

Generated summary artifact for 2603.28052

Thesis

Meta-Harness, an outer-loop system that automates harness engineering by searching over harness code with full filesystem access to prior experience, can discover more effective, generalizable, and faster-converging context management strategies than manual designs or prior text optimization methods, leading to significant performance gains across diverse LLM applications.

Core Problem

The performance of large language model (LLM) systems is heavily reliant on their "harness" (the code that determines information storage, retrieval, and presentation), yet these harnesses are still largely designed manually. Existing text optimization methods are ill-suited for this task due to overly compressed feedback, memorylessness, or restricted feedback to short templates/summaries.

Key Novelty

An end-to-end outer-loop system that automates harness engineering for LLMs by using a coding agent with full filesystem access to prior experience (source code, execution traces, scores) to search and optimize harness code.

Key Contributions

  • Meta-Harness achieved 7.7 points higher accuracy than the state-of-the-art ACE [59] in online text classification while using 4x fewer context tokens.
  • It matched the best prior text optimizers' final accuracy within 4 evaluations and ultimately surpassed them by over 10 points.
  • The discovered retrieval strategy for math reasoning improved accuracy by 4.7 points on IMO-level problems over a 'no retriever' baseline across five held-out models.
  • Meta-Harness outperformed the strong hand-engineered Terminus-KIRA by 1.7% pass rate and Goose by 2.1% pass rate on TerminalBench-2 for Claude Opus 4.6 and Haiku 4.5 agents respectively.
  • Discovered harnesses generalize well to out-of-distribution classification datasets and unseen base models in the math reasoning setting.

Results

  • Meta-Harness significantly outperforms prior hand-designed harnesses and text optimizers in online text classification, achieving higher accuracy with substantially less context.
  • The method successfully discovers effective retrieval strategies for math reasoning on IMO-level problems, surpassing various baselines including dense and sparse retrieval.
  • Meta-Harness automatically discovers harnesses that outperform strong human-engineered agents on the challenging TerminalBench-2 agentic coding benchmark.
  • Providing the coding agent with full filesystem access to raw prior code and execution traces is crucial for enabling effective harness search and performance gains.

Limitations

  • The current study evaluates Meta-Harness with one particularly strong coding-agent proposer (Claude Code); further research is needed to explore how its effectiveness varies across different proposer agents.
  • While the discovered harness for TerminalBench-2 is specialized to its regime, the overall methodology is demonstrated to be generally effective, suggesting broader applicability with careful adaptation.
