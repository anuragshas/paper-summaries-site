Skills-Coach: A Self-Evolving Skill Optimizer via Training-Free GRPO

Authors: Yu Tian, Jiawei Chen, Lifan Zheng, Mingxiang Tao, Xinyi Zeng, Zhaoxia Yin, Hang Su, Xian Sun

Source: https://arxiv.org/abs/arXiv:2604.27488

Generated summary artifact for 2604.27488

Thesis

Skills-Coach is a novel automated framework that significantly enhances the self-evolution capabilities of skills within Large Language Model (LLM)-based agents by systematically exploring skill boundaries, optimizing skill prompts and code, and rigorously evaluating performance, thereby addressing the current fragmentation of the skill ecosystem and fostering the development of more robust and adaptable LLM-based agents.

Core Problem

The current skill ecosystem for LLM-based agents is fragmented, characterized by abundant skills designed for localized use cases that struggle to systematically cover comprehensive functional requirements, leading to functional gaps and integration bottlenecks.

Key Novelty

Skills-Coach introduces a novel automated framework for Skill Self-Evolution in LLM-based agents, employing a training-free optimization approach to enhance skill capabilities and address the fragmented skill ecosystem.

Key Contributions

  • Overall average score increased from 0.37 to 0.84, representing a substantial 127% relative growth.
  • Overall pass rate dramatically improved from 33.59% to 88.02%, indicating a robust increase of 54.43%.
  • For skills in the 'Exceptional Improvement' category, some experienced dramatic improvements, with scores leaping from 0.0 to 1.0 and pass rates rising from 0% or lower levels to 100%.
  • Both instruction-only and code-inclusive skills achieved over a 50% increase in pass rate, with code-inclusive skills showing the largest relative improvement.

Results

  • Skills-Coach significantly improves skill performance across all evaluation metrics on the Skill-X benchmark.
  • The framework is effective for both instruction-only and code-inclusive skills, with code-inclusive skills showing the largest relative improvement.
  • Performance gains are consistently observed across all task difficulties, with advanced tasks demonstrating an even greater magnitude of improvement.
  • The optimization yields transformative improvements for underperforming skills but shows diminishing returns for already high-performing skills, suggesting strategic allocation of optimization resources is crucial.
