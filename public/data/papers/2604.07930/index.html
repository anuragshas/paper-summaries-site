Unified Supervision for Walmart’s Sponsored Search Retrieval via Joint Semantic Relevance and Behavioral Engagement Modeling

Authors: Shasvat Desai, Md Omar Faruk Rokon, Jhalak Nilesh Acharya, Isha Shah, Hong Yao, Utkarsh Porwal, Kuang-chih Lee

Source: https://arxiv.org/abs/arXiv:2604.07930

Generated summary artifact for 2604.07930

Thesis

In sponsored search, bi-encoder retrievers should be trained with semantic relevance as the foundation of the objective, using behavioral engagement only to refine preferences among relevant candidates to overcome data sparsity and noise.

Core Problem

Standard engagement-based supervision for retrieval is noisy and structurally sparse in sponsored search due to ad-slot auctions, budgets, and limited display positions.

Key Novelty

A unified supervision framework that makes semantic relevance the primary signal for bi-encoder training while using engagement only to refine ordering among relevant candidates.

Key Contributions

  • Offline evaluation on 30,303 queries covering head and long-tail traffic
  • Online A/B testing on live Walmart production traffic
  • Ablation study comparing relevance-only vs. relevance-plus-engagement supervision

Results

  • Semantic relevance should define retrieval eligibility, while engagement should refine preference among relevant items.
  • Unified supervision significantly outperforms production systems using only engagement signals.
  • Incorporating production rank priors helps the model identify and learn from hard negatives.

Limitations

  • Reliance on LLM-based labeling might introduce teacher biases into the bi-encoder.
  • The framework is optimized for sponsored search and may require tuning for organic search.
