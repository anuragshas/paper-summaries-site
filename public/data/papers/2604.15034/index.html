Autogenesis: A Self-Evolving Agent Protocol

Authors: Wentao Zhang

Source: https://arxiv.org/abs/arXiv:2604.15034

Generated summary artifact for 2604.15034

Thesis

The Autogenesis Protocol (AGP) is a two-layer self-evolution protocol that decouples "what evolves" from "how evolution occurs" to provide a principled foundation for building modular, traceable, and safely improvable agentic systems, demonstrated by the Autogenesis System (AGS) which achieves significant performance improvements across diverse benchmarks.

Core Problem

Existing LLM-based agent systems under-specify cross-entity lifecycle and context management, version tracking, and evolution-safe update interfaces, leading to monolithic compositions, brittle glue code, and difficulties in achieving robust autonomy. Self-evolving agent implementations are fragmented and ad hoc, lacking shared standards for composable and auditable evolution.

Key Novelty

A two-layer self-evolution protocol (Autogenesis Protocol - AGP) that rigorously decouples the definition of evolvable resources from the mechanisms governing their evolution.

Key Contributions

  • Achieved state-of-the-art performance on the GAIA Test split (89.04% average Pass@1), outperforming ToolOrchestra by 1.66 percentage points, with a 33.34% improvement on Level 3 tasks.
  • Demonstrated relative pass-rate improvements ranging from 10.1% (Python3) to 26.7% (Kotlin) on the LeetCode benchmark, along with significant reductions in execution-blocking errors.
  • Showed up to 100% improvement on AIME benchmarks for weaker models (gpt-4o, gpt-4.1) and reliable improvements for stronger models (gemini-3-flash-preview, grok-4.1-fast).
  • Consistently reduced runtime for accepted solutions across all five coding languages, with reductions up to 46.4% in C++.

Results

  • Self-evolution significantly improves performance across diverse models and benchmarks, with weaker models gaining more and stronger models showing reliable but modest gains.
  • Combining prompt+solution evolution consistently outperforms single-strategy evolution (prompt-only or solution-only).
  • Math benchmarks (AIME) show larger relative gains from evolution compared to science QA (GPQA-Diamond), as reflection can target more intermediate failure points.
  • Tool evolution yields substantial gains on general agent tasks, especially on harder task tiers (GAIA Level 3), where complex multi-step tool chains are required.
  • On algorithmic coding, self-evolution consistently improves pass rates (PR) and runtime efficiency (AR) across all languages, with largest gains in compiled languages like C++ and Java.
  • The evolving agent becomes more competitive against human submissions (ARB, AMB) in terms of runtime and memory.
